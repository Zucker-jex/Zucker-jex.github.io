# 旧世将尽（KYRots）角色扮演管理平台使用指南 <!--more-->

**旧世将尽（KYRots）角色扮演管理平台**

本指南面向两类使用者，请按你的身份选择对应章节：

| 身份       | 章节                                                | 说明                                                         |
| ---------- | --------------------------------------------------- | ------------------------------------------------------------ |
| **玩家**   | [第一部分：玩家使用指南](#第一部分玩家使用指南)     | 补全角色信息、查看审核与白名单状态、管理角色与关系、提交工单 |
| **管理员** | [第二部分：管理员使用指南](#第二部分管理员使用指南) | 预置账户、审核角色、管理白名单、维护字段模板、审计与运维     |

> **开始之前，请先理解平台边界。**
>
> 本平台是 **SteamID 级准入管理与玩家信息登记平台**，不是游戏内账户或角色的审批系统。
>
> - 僵尸毁灭工程的登录机制**仅校验 SteamID**。一个 SteamID 可以登录服务器，并可在游戏内自行注册多个游戏账户、创建多个角色。该行为发生在游戏服务器内部，平台**不感知、不审查、不阻止**。
> - 白名单是 **SteamID 粒度的门禁**，不是角色粒度的审批。审核通过的含义是「**允许该 SteamID 连接服务器**」，不是「批准某个角色进入游戏」。
> - 平台侧登记的主角色、副角色与关系网都是**玩家声明性登记**，与游戏内实际角色**没有技术绑定**，平台**不提供**自动核对能力。

# 第一部分：玩家使用指南

## 1. 登录

访问平台首页，进入登录页。页面顶部有两个切换标签：

- **玩家登录** —— 你使用这个
- **管理员登录** —— 管理员使用

### 登录凭据

| 字段        | 填写内容                                    |
| ----------- | ------------------------------------------- |
| **SteamID** | 管理员为你预置的 **SteamID64**（17 位数字） |
| **密码**    | 管理员发放的初始密码，或你自行修改后的密码  |

> **首次登录**请使用管理员预置的 SteamID 与初始密码。登录后系统会强制你补全主角色信息并设置新密码。

### 登录后的跳转

| 你的状态         | 跳转到                 |
| ---------------- | ---------------------- |
| 尚未补全信息     | 自动进入**补全信息**页 |
| 已补全、等待审核 | 进入**概览**页         |
| 已加入白名单     | 进入**概览**页         |

### 常见登录问题

| 提示                       | 原因与处理                                                                          |
| -------------------------- | ----------------------------------------------------------------------------------- |
| 请填写完整信息             | 账号或密码为空                                                                      |
| SteamID 必须为 17 位纯数字 | SteamID 格式不正确（位数不对或含非数字字符）。页面会直接拦截，不发起请求            |
| 登录失败，请检查账号与密码 | 凭据错误、填了平台用户名而非 SteamID，或账户已被禁用。请确认使用 17 位 SteamID 登录 |
| 登录过于频繁               | 触发了登录限流（默认每分钟 5 次），请稍后再试                                       |

> 输入框的占位提示为「请输入 17 位 SteamID64」。

## 2. 首次补全主角色

首次登录后，系统会强制跳转到**补全信息**页。在补全完成并通过审核之前，你无法访问其他功能页面。

### 需要填写的内容

| 字段                        | 说明                                                          |
| --------------------------- | ------------------------------------------------------------- |
| **平台用户名**              | 必填。你在平台内的显示名，不得超过 100 个字符，不可与他人重复 |
| **新密码**                  | 必填。**8–128 位，且必须同时包含字母与数字**                  |
| **确认新密码**              | 必填。需与上一项一致                                          |
| **角色名**                  | 必填。你的主角色名称                                          |
| **角色信息（模板版本 vN）** | 由管理员维护的字段模板决定，带 `*` 的为必填项                 |

### 关于字段

- 标有 **审核依据** 徽章的字段，其内容会作为管理员审核的判断依据。
- 字段类型包括文本、数字、日期、枚举（下拉选择）、布尔（是/否）。
- 每个字段可能有长度、数值范围等约束，不符合时会在该字段下方提示。

### 使用 XLSX 快捷填写

如果字段较多，可以下载模板离线填写后导入：

1. 点击**下载模板**，得到 `KYRots_角色信息卡模板.xlsx`。
2. 在 Excel 中按列填写。**不要修改表头**。
3. 回到页面点击**导入 XLSX**，选择填好的文件。
4. 系统会提示「成功导入！请检查内容，补全缺失的字段后提交。」——请务必核对导入结果。

> 导入只做回填，不会自动提交。你仍需检查内容并手动点击提交。

### 提交

点击**提交审核**。提交成功后进入**审核进度**页。

> **提交后会发生什么？** 你的账户状态变为「待管理员审核」，主角色进入审核队列。管理员审核通过后，系统会自动执行 RCON 指令把你的 SteamID 加入服务器白名单。

### 如果被驳回

管理员驳回时会填写理由。你会看到：

- 账户状态变为「**补全被驳回**」
- 概览页出现「补全信息已被驳回」提示
- 补全页可重新进入修改

修改后重新提交即可。**被驳回状态下重新提交时，密码栏可以留空**（表示不修改密码）。

## 3. 查看审核进度

左侧菜单 → **审核进度**

这一页展示：

- **角色状态** —— 待审核 / 审核通过 / 已驳回
- **提交快照** —— 你提交时的字段内容冻结副本，包含角色类型、角色名等

> **快照说明**：快照为提交瞬间的冻结副本，**一经写入永不更新**。即使管理员之后修改了字段模板，历史快照仍按当时的模板版本渲染，不会错乱。

> **审核目的说明**：审核目的为身份核验与准入决策，**不是对游戏内角色的批准**。

## 4. 查看白名单状态

左侧菜单 → **白名单状态**

| 显示             | 含义                                  |
| ---------------- | ------------------------------------- |
| **未加入白名单** | 你的 SteamID 尚未被加入服务器白名单   |
| **已加入白名单** | 你的 SteamID 已被允许连接服务器       |
| **已移出白名单** | 你的 SteamID 已被移出，无法连接服务器 |

> **重要**：白名单状态**仅由服务器 RCON 执行结果与管理员手动切换驱动**。它反映的是「你的 SteamID 能否连接服务器」，与你的角色审核状态是两件事。

## 5. 我的角色

左侧菜单 → **我的角色**

页面顶部显示统计：`共 N 个角色 · 副角色 X / Y`（Y 为管理员设置的副角色上限）。

### 自助编辑字段

对于管理员标记为「玩家可自助编辑」的字段，你可以直接修改：

1. 在角色卡片上点击**自助编辑**。
2. 修改字段值。
3. 点击**保存**。

> **自助编辑的语义**：仅可编辑被授权字段；提交后**立即生效，不进入审核队列**，但会留下变更记录。如果当前没有可自助编辑的字段，页面会提示「当前没有可自助编辑的字段。」

### 变更历史

点击**变更历史**可查看该角色的字段级变更记录，包括每次修改的时间、字段与前后值。

### 状态标识

| 标识       | 含义                               |
| ---------- | ---------------------------------- |
| 待审核     | 已提交，等待管理员审核             |
| 审核通过   | 管理员已通过                       |
| 已驳回     | 管理员已驳回，可修改后重新提交     |
| 待重新审核 | 因模板变更或字段修改，需要重新审核 |

## 6. 添加副角色

左侧菜单 → **我的角色** → **添加副角色**

### 前置条件

- 你的主角色必须已经补全并通过审核。
- 副角色数量未达到管理员设置的上限（默认 3 个）。
- 没有未处理的**阻断类**模板更新通知。

### 操作步骤

1. 填写**角色名**（必填）。
2. 填写角色信息字段（同样支持**下载模板**与**导入 XLSX**）。
3. 点击**提交审核**。

### 副角色的语义

> **副角色审核通过不改变游戏侧任何状态。** 它不会触发 RCON，不会改变你的白名单状态，也不会改变账户状态。副角色是你在平台侧的**额外角色声明**，供管理员参考。

## 7. 关系网

左侧菜单 → **关系网**

这一页以**星图**形式展示你的角色关系，并提供申请与审批操作。

### 发起关系申请

1. 点击**发起关系申请**。
2. 选择源角色（你自己的角色）、目标角色（对方角色）与关系模板（如「挚友」）。
3. 点击**发送申请**。

> 不能对自己发起关系。若已存在相同关系或正在审核中，会提示「已存在该关系或正在审核中」。

### 处理收到的申请

| 状态             | 含义                           | 可执行操作          |
| ---------------- | ------------------------------ | ------------------- |
| **待确认**       | 对方发来申请，等待你处理       | **接受** / **拒绝** |
| **等待对方确认** | 你发出的申请，等待对方处理     | 无                  |
| **已确立**       | 双方已确认                     | **申请解除**        |
| **已拒绝**       | 申请被拒绝                     | 无                  |
| **解除审批中**   | 已提交解除申请，等待管理员审批 | 无                  |

- 点击**拒绝**时需要填写拒绝理由。
- 点击**申请解除**时需要填写解除理由，该理由会提交给管理员审批。

> **关系操作不触发 RCON**，不影响你的白名单状态。

## 8. 工单

左侧菜单 → **工单**

工单是你与管理员沟通的结构化渠道。

> **工单的语义**：工单**不直接改变业务状态**，不触发 RCON，也不会改变你的账户或白名单状态。它只是沟通与留痕渠道。

### 创建工单

1. 点击**创建工单**。
2. 填写：
   - **主题** —— 必填，不超过 200 个字符，请简要概括问题
   - **分类** —— 账户 / 白名单 / 角色 / 举报 / 申诉 / 其他 / 游戏BUG / 平台BUG
   - **优先级** —— 低 / 普通 / 高 / 紧急
   - **描述** —— 必填，请详细描述你遇到的问题或需要协助的事项
3. 点击**提交工单**。

### 工单状态

| 状态       | 含义                   |
| ---------- | ---------------------- |
| **待处理** | 已提交，等待管理员受理 |
| **处理中** | 管理员正在处理         |
| **已解决** | 管理员已给出解决方案   |
| **已关闭** | 工单已结束             |

### 回复与附件

进入工单详情后可以：

- **回复工单** —— 在输入框填写内容后点击**发送回复**
- **上传附件** —— 单文件不超过 10 MB，单工单最多 20 个附件

支持的附件类型：

| 类别   | 扩展名                               |
| ------ | ------------------------------------ |
| 图片   | `.png` `.jpg` `.jpeg` `.webp`        |
| 文本   | `.txt` `.log`                        |
| 文档   | `.pdf` `.doc` `.docx` `.xls` `.xlsx` |
| 压缩包 | `.zip` `.rar` `.7z`                  |

> **无需先回复即可上传附件。** 直接上传时，系统会自动生成一条内容为「[上传了附件: 文件名]」的记录，便于追溯。

> 若附件下载失败，页面会提示「附件下载失败，请检查网络或重新登录」。

### 关闭与重新打开

- 点击**关闭工单**可自行关闭。
- 已关闭的工单可以重新打开，但**最多 3 次**。达到上限后按钮会显示「已达重新打开上限 (3/3)」。

### 内部备注

工单详情中可能出现**内部备注**。这是管理员之间的沟通内容，**仅管理员可见**，玩家侧查询时会被过滤。

## 9. 站内信通知

页面右上角的**铃铛图标**显示未读数量（每 30 秒自动刷新）。

点击铃铛可查看通知列表。通知来源包括：

- 关系申请、关系被接受、关系被拒绝
- 工单回复
- 管理员发送的系统通知与全站公告

点击通知即可标记为已读，并跳转到相关页面（关系类通知跳转到**关系网**）。

### 我的通知

左侧菜单 → **我的通知**

这一页展示你的**全部通知**（最多 100 条），按时间倒序排列，已读的会以半透明显示。若没有任何通知，会显示「暂无任何通知」。

> 铃铛菜单只显示最近的通知，**我的通知**页是完整列表。

## 10. 模板更新通知

当管理员修改了字段模板，且变更影响到你已填写的字段时，页面顶部会出现**模板更新横幅**。

### 横幅内容

横幅会显示需要补全的字段数量，例如：

> 共 N 个字段需补全（阻断类），未补全前无法提交副角色、编辑字段

### 阻断的含义

| 通知类型                                     | 影响                                         |
| -------------------------------------------- | -------------------------------------------- |
| **阻断类**（字段缺失、类型不匹配、校验失败） | 未补全前**无法**提交副角色、无法自助编辑字段 |
| 非阻断类                                     | 仅提示，不限制操作                           |

### 处理方式

点击横幅上的**去补全**，按提示补全字段后确认。完成后阻断解除。

> **重要**：模板变更**不会**自动改写你已填写的内容。系统只生成通知与阻断标记，具体内容始终由你自己确认与修改。

## 11. 修改密码与个人资料

点击右上角头像 → 打开**用户设置**弹窗。

### 修改密码

1. 填写旧密码与新密码。
2. 新密码需**至少 8 位**，且两次输入一致。
3. 保存后系统会提示「密码已修改，即将重新登录...」，你需要用新密码重新登录。

### 修改资料

可修改**显示名称**、**QQ** 与**邮箱**，保存后提示「资料已更新，刷新后生效」。

### 被强制修改密码时

如果管理员重置了你的密码，你下次登录时会被**强制要求修改密码**：

- 改密弹窗会**自动打开且无法关闭**，必须先完成修改才能使用其他功能。
- 此时**无需输入旧密码**，只需填写新密码并确认。
- 修改成功后，强制标记被清除，你可以正常使用平台。

> 强制改密期间，你的账户状态**不会**被改变。原本待补全的仍然去补全，原本已加入白名单的登录后直接进首页。

## 13. 玩家常见问题

**Q：我提交了信息，为什么白名单还是「未加入白名单」？**
A：审核通过后系统会异步执行 RCON 指令，通常几秒内完成。若长时间未变化，请通过工单联系管理员。

**Q：审核通过是不是意味着我的角色被批准了？**
A：不是。审核通过的含义是「允许你的 **SteamID** 连接服务器」。平台不审查、也无法感知你在游戏内创建的角色。

**Q：我可以登记多个角色吗？**
A：可以。主角色 1 个，副角色数量由管理员设置上限（默认 3 个）。副角色审核通过不改变游戏侧任何状态。

**Q：为什么我不能编辑某些字段？**
A：只有管理员标记为「玩家可自助编辑」的字段你才能修改。其他字段需要联系管理员。

**Q：为什么我不能提交副角色？**
A：可能原因：主角色尚未通过审核、副角色已达上限、或存在未处理的阻断类模板更新通知。

**Q：我的 SteamID 被移出白名单了，怎么办？**
A：白名单状态由管理员手动切换或 RCON 执行结果驱动。请通过工单联系管理员了解原因。

**Q：忘记密码怎么办？**
A：请联系管理员重置。管理员重置后会给你一个临时密码，你首次登录时会被强制修改。

**Q：可以用平台用户名登录吗？**
A：不可以。登录框标签虽写作「SteamID / 平台用户名」，但服务端只接受 SteamID64。请使用 17 位 SteamID 登录。

# 第二部分：管理员使用指南

## 1. 登录

管理员使用**独立登录入口**，与玩家登录分离。

- 访问 `/admin/login`，或在登录页切换到**管理员登录**标签
- 凭据为**管理员用户名 + 密码**（不是 SteamID）

### 首次登录强制改密

如果管理员账户是新建的，或密码被超级管理员重置过，首次登录时会被**强制要求修改密码**，此时无需输入旧密码。

## 2. 账户预置

左侧菜单 → **基础管理** → **账户预置**

这是玩家准入流程的起点：管理员先预置 SteamID，玩家才能登录并补全信息。

### 单个创建

1. 点击创建账户。
2. 填写 **SteamID**（必填，17 位十进制数字）。
3. 提交后系统自动生成初始密码。

> **SteamID 校验**：平台仅接受 `AccountKind::Individual`、`Universe::Public`、`InstanceKind::Desktop` 且 Account ID 非零的取值。格式错误会提示「SteamID 应为 17 位十进制数字」。

### 批量导入（XLSX）

1. 点击**下载模板**，得到 `kyrots_import_template.xlsx`。
2. 模板只有一列 `steamid`。
3. 填写后上传导入。

> **关键注意事项**：请确保 `steamid` 列格式为**文本**（17 位纯数字）。若 Excel 将其识别为数字，会发生精度丢失变成科学计数法。系统检测到这种情况会提示：
>
> > 检测到 SteamID 为数字格式（已发生精度丢失变成科学计数法）。请重新下载模板，并在 Excel 中先将该列设置为"文本"格式后再粘贴数字。

导入结果会显示总行数、成功数与失败数，失败行会列出具体原因。

### 初始密码的分发

创建或导入成功后，系统会显示**临时密码**：

> 临时密码仅在此刻显示，请务必立即下载！

- 点击**下载临时密码 Excel** 保存。
- 若当时未下载，可稍后到列表中通过**重置密码**重新生成。

> 玩家首次登录后会被强制修改密码，临时密码随即失效。

### 其他操作

| 操作         | 说明                                 |
| ------------ | ------------------------------------ |
| **重置密码** | 为账户生成新的临时密码               |
| **账户详情** | 查看该账户的角色、字段详情与巡查记录 |

## 3. 审核队列

左侧菜单 → **审核与受理** → **审核队列**

### 筛选与搜索

- 按状态筛选：**待审核** / **已通过** / **已驳回**
- 搜索框支持按角色、平台名或 SteamID 搜索

### 审核主角色

点击**查看详情**进入审核详情页。

**审核通过的前置条件**：

> 主角色首次审核**必须上传至少一份审核依据附件**（xlsx 或图片）。未上传时点击通过会提示「主角色首次审核必须上传至少一份审核依据附件（xlsx 或 图片）」。

**操作步骤**：

1. 核对提交快照中的字段内容。
2. 上传审核依据（点击**上传 xlsx**，也支持图片）。
3. 点击**审核通过**。

通过后系统提示：

> 审核已通过，RCON 白名单添加任务已入队

> **通过的含义**：把该 SteamID 加入服务器白名单。审核目的为身份核验与准入决策，**不是对游戏内角色的批准**。

**驳回**：

1. 点击**驳回**。
2. 填写驳回理由（**必填**）。
3. 点击**确认驳回**。

驳回后账户状态回退为「补全被驳回」，玩家可修改后重新提交。

### 审核副角色

副角色审核流程相同，但：

- **附件可选**（不强制上传）
- 通过后提示「副角色审核已通过（不触发白名单、不影响游戏侧）」
- **不会执行任何 RCON 指令**，账户白名单状态保持不变

### 附件管理

- 可下载或删除已上传的附件。
- **主角色审核至少需要保留一份 xlsx 格式的审核依据**，无法删除最后一个 xlsx。

### 关于快照

> 快照一经写入永不更新；按快照记录的模板版本渲染，模板变更后历史快照显示不错乱。

## 4. 白名单总览

左侧菜单 → **审核与受理** → **白名单总览**

这一页对比**平台侧记录**与**服务器侧实际白名单**，并支持手动切换。

### 查看与同步

| 操作                 | 说明                               |
| -------------------- | ---------------------------------- |
| **从服务器同步**     | 只读拉取服务器白名单，生成差异标记 |
| **查看游戏端白名单** | 查看 `allowedsteamid` 表的原始内容 |
| **仅显示差异**       | 只显示平台侧与服务器侧不一致的账户 |

> **同步的语义**：同步**只做差异展示**，不会自动修复或自动对齐。若 PZ DB 未启用或不可达，会提示「同步功能暂时不可用。手动切换白名单不受影响。」

### 手动切换

1. 在账户行点击**移出白名单**或**加入白名单**。
2. 填写**操作理由**（必填）。
3. 确认执行。

移出时会显示影响提示：

> 将阻止该 SteamID 连接服务器，影响其名下所有游戏内账户。
> 执行结果将记入审计。

> **重要**：白名单变更**只能通过 RCON 执行**，这是唯一路径。PZ 存档数据库始终以只读方式访问，平台不会直接写入。

## 5. 字段模板

左侧菜单 → **数据与运维** → **字段模板**

字段模板决定玩家补全主/副角色时需要填写哪些字段。

### 字段类型

| 类型     | 说明          | 可用约束                                     |
| -------- | ------------- | -------------------------------------------- |
| **文本** | 单行/多行文本 | 最小长度、最大长度                           |
| **数字** | 数值          | 最小值、最大值                               |
| **日期** | 日期选择      | —                                            |
| **枚举** | 下拉选择      | 选项（每行一个）、最大可选数量（留空为单选） |
| **布尔** | 是/否         | —                                            |

### 字段属性

| 属性               | 说明                                               |
| ------------------ | -------------------------------------------------- |
| **显示名称**       | 玩家看到的中文字段名，可随时修改，不影响历史数据   |
| **字段类型**       | 见上表                                             |

### 关键约束

> **字段机器标识（field_key）创建后任何人（含管理员）不可修改**，且管理员在 Web 界面**不可见** field_key。系统在创建字段时自动生成。

### 编辑与版本

1. 点击**编辑**修改字段。
2. 填写**变更摘要**（可选），例如「新增木工等级字段」。
3. 点击**保存并生成新版本**。

每次保存都会生成新的模板版本。模板变更后：

- 系统为受影响账户生成**模板更新通知**
- 存在阻断类问题时，玩家在补全前无法提交副角色或编辑字段
- **不会直接改写玩家已填写的内容**

### 废弃与恢复

- 点击**已废弃**可将字段软删除（历史数据保留）。
- 点击**启用**可恢复已废弃字段。

### 快捷操作

**新增技能等级字段** —— 一键添加 `number` 类型的技能等级字段，默认允许玩家自助编辑，不作为审核依据。

## 7. 工单队列

左侧菜单 → **审核与受理** → **工单队列**

管理所有玩家工单，支持分配、状态流转、优先级调整。

### 筛选

可按状态、分类、优先级筛选。点击**重置**清空全部筛选条件。

### 模糊搜索

筛选区提供**模糊搜索**输入框，占位提示为「搜索标题、单号、发起人、被分配...」。

搜索在服务端联表执行，可匹配：

- 工单**标题**（`subject`）
- 工单**单号**（`ticket_no`）
- **发起人**的平台用户名（玩家）
- **被分配人**的用户名或显示名（管理员）

### 处理工单

进入工单详情后可执行：

| 操作           | 说明                                                 |
| -------------- | ---------------------------------------------------- |
| **回复工单**   | 在输入框填写内容后点击**发送回复**                   |
| **内部备注**   | 勾选「内部备注（仅管理员可见）」后发送，玩家侧不可见 |
| **上传附件**   | 无需先回复，直接上传即可                             |
| **状态变更**   | 流转工单状态，需填写**必填**的说明                   |
| **分配**       | 搜索管理员进行分配，留空可取消分配                   |
| **优先级变更** | **降级优先级时必填理由**                             |

### 附件类型

与玩家侧一致：图片（`.png` `.jpg` `.jpeg` `.webp`）、文本（`.txt` `.log`）、文档（`.pdf` `.doc` `.docx` `.xls` `.xlsx`）、压缩包（`.zip` `.rar` `.7z`）。单文件不超过 10 MB，单工单最多 20 个。

### 状态流转

`待处理` → `处理中` → `已解决` → `已关闭`

- 标记为**已解决**时必须填写解决说明。
- 非法状态跳转会被拒绝。

### 硬约束提醒

> 工单**不触发 RCON**、**不改变业务状态**。工单正文与内部备注**不进审计载荷**。

## 10. 快照恢复

左侧菜单 → **数据与运维** → **快照恢复**

用于离线核查服务器存档数据。

### 功能

| 功能                   | 说明                                                 |
| ---------------------- | ---------------------------------------------------- |
| **快照列表**           | 查看自动备份的 `players.db` 快照文件                 |
| **玩家检索**           | 在指定快照中按用户名过滤查找玩家                     |
| **解析玩家数据**       | 解析玩家 BLOB，展示特质、技能与完整背包树            |
| **重新加载服务器字典** | 重载 `WorldDictionaryReadable.lua`，用于物品名称翻译 |

### 自动备份

系统在启动时立即执行一次备份，之后按配置的间隔自动备份 `players.db`，并保留指定数量的快照。

若启用了整点备份（`pz_db.enable_hourly_backup`，默认开启），首次定时备份会等到**下一个整点**再开始，之后按间隔周期执行。

### 只读保证

> 快照恢复模块对 `players.db` 始终以 `mode=ro` 与 `query_only(1)` 打开，**严禁写入**。

### 可用操作

| 操作                 | 说明                                                                                     |
| -------------------- | ---------------------------------------------------------------------------------------- |
| **启用 / 禁用**      | 切换管理员状态                                                                           |
| **重置密码**         | 生成新的强密码。重置后该管理员的登录状态**立即失效**，并在下次登录时**强制要求修改密码** |
| **提升为超级管理员** | 将 ADMIN 提升为 SUPER_ADMIN                                                              |
| **降级**             | 将 SUPER_ADMIN 降为 ADMIN                                                                |
| **修改资料**         | 修改 QQ、邮箱、SteamID 等（**不可改 username 与 role**）                                 |

### 安全约束

> - **不能禁用或降级自己。**
> - **不能禁用或降级最后一名活跃的 SUPER_ADMIN**（通过 advisory lock 保证并发安全）。
> - 重置密码或角色变更后，系统会**撤销目标管理员的 refresh token**，使其立即失效。

## 14. 管理员常见问题

**Q：为什么我看不到「管理员管理」菜单？**
A：该菜单仅对 SUPER_ADMIN 可见。普通管理员无法访问相关接口。

**Q：审核通过后白名单没有立即生效？**
A：RCON 指令通过异步队列执行，默认每 3 秒轮询一次。可在**白名单总览**页点击**从服务器同步**确认实际状态。若持续失败，检查 RCON 连接与审计日志中的 `RCON_EXEC_FAILED` 事件。

**Q：为什么不能删除最后一个 xlsx 附件？**
A：主角色审核至少需要保留一份 xlsx 格式的审核依据，这是强制约束。

**Q：修改字段模板后，玩家的数据会被自动改写吗？**
A：不会。模板变更只生成通知与阻断标记，**不直接改写**玩家字段。玩家需自行确认并补全。

**Q：为什么「从服务器同步」提示不可用？**
A：PZ 存档数据库未启用（`pz_db.enabled=false`）或不可达。手动切换白名单不受影响。

**Q：审计记录可以删除吗？**
A：不可以。审计表仅追加，数据库层有禁改触发器，平台也不提供任何修改或删除入口。

**Q：管理员用户名可以用数字吗？**
A：不可以。用户名不得为纯数字，以避免与 SteamID 登录混淆。

**Q：重置玩家密码后，玩家的账户状态会变吗？**
A：不会。重置密码只更新密码并置位强制改密标记，**保持玩家原有状态**。原本待补全的登录后仍去补全，原本已加入白名单的登录后直接进首页。

**Q：为什么玩家说重置密码后不用输旧密码？**
A：这是设计行为。被重置密码的账户处于强制改密状态，此时免旧密码校验，只需设置新密码。修改成功后标记自动清除。

**Q：通知中心里「全体玩家」和「全站公告」有什么区别？**
A：「全体玩家」只发给玩家账户；「全站公告」同时发给管理员与全体玩家，且管理员侧内容会带 `[全站公告]` 前缀。

**Q：普通管理员能看到其他管理员发出的通知吗？**
A：不能。普通管理员的发件箱只显示自己发出的通知；只有 SUPER_ADMIN 能看到全站所有管理员发出的通知。

**Q：工单搜索能搜到什么？**
A：模糊搜索会联表匹配工单标题、单号、发起人的平台用户名，以及被分配人的用户名或显示名。

**Q：如何批量预置玩家？**
A：使用**账户预置**页的 XLSX 导入功能，或使用 CLI 命令 `./kyrots import-accounts -file accounts.xlsx -admin <你的用户名>`。

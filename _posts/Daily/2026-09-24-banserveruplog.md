# BanServer 版本更新日志 <!--more-->

---

## v1.0 —— 项目初始版本

**发布时间**：2026-09-21 前（项目基础版本）

**核心功能首次上线**

### 用户系统

- 服主注册（用户名、密码、QQ、邮箱）
- 注册后需管理员审批才能使用
- 登录 / 登出
- 账号状态管理（待审批 / 正常 / 已禁用）
- 角色分级（服主 / 管理员）

### 服务器管理

- 服主可创建自己的服务器
- 支持重命名、删除服务器
- 一个账号可拥有多个服务器

### 封禁管理

- 提交封禁记录（SteamID、游戏用户名、原因、封禁时间、解封时间）
- 支持永久封禁和临时封禁
- 编辑已提交的封禁记录
- 撤销（解封）封禁
- 冲突检测：防止同一 SteamID 被重复封禁
- 冲突处理：自己的记录可编辑，别人的记录可申请介入

### 介入申请

- 服主可对其他人的封禁提起申诉
- 提交申请理由
- 查看申请状态（待处理 / 已解决 / 已拒绝）
- 查看申请详情

### 管理员功能

- 审批新用户注册（通过 / 拒绝）
- 启用 / 禁用用户
- 重置用户密码
- 处理介入申请（标记解决 / 拒绝）
- 维护管理员联系方式（QQ / 邮箱 / 其他）
- 查看全站所有封禁记录

### 公开功能

- 无需登录查看公开封禁列表
- 按用户名 / 原因 / SteamID 搜索
- 按 SteamID 精确查询玩家封禁状态

### 系统能力

- 定时检查封禁到期，自动标记为过期
- 封禁变更审计日志
- 健康检查接口
- 完整的 RESTful API

## v1.1 —— 上线部署与稳定性修复

**发布时间**：2026-09-22

**里程碑**：项目首次在树莓派上稳定运行并接入公网

### 新增能力

**HTTPS 加密访问**

- 接入域名和 SSL 免费证书
- 全站 HTTPS 加密
- 证书自动续期机制
- 浏览器安全锁标识

**"我的服务器"页面**

- 补全了此前缺失的服务器管理界面
- 支持添加、重命名、删除服务器

**介入申请详情页**

- 点击介入申请可查看完整信息
- 展示申请 ID、SteamID、申请人、关联封禁、状态、处理时间等

**公告显示区域**

- 公开页和面板页预留公告展示位置

### 功能修复

**封禁编辑功能**

- 修复解封时间无法保存的问题
- 修复时间格式解析错误

**封禁状态显示**

- 解封时间列由"已过期"文字改为显示真实日期
- 用颜色区分状态：未过期（黄）/ 已过期（红）/ 永久封禁（红）

**到期检查优化**

- 自动检查间隔从 5 分钟缩短到 1 分钟
- 封禁到期后能更快标记为过期

**服务器移除限制**

- 服务器下有封禁记录时，禁止直接删除
- 提示用户先处理封禁数据

### 构建与部署修复

- 修复中文字符校验规则问题
- 修复路由重复注册导致服务无法启动
- 修复数据库连接配置
- 修复前端类型检查错误
- 修复多个代码层面的编译问题

### 架构改进

- 前后端端口统一规划
- 容器化部署标准化
- 数据库连接参数优化

## v1.2 —— 安全加固

**发布时间**：2026-09-23 上午

**里程碑**：完成全面安全审计并修复已知隐患

### 高危安全修复

**查询注入防护**

- 封禁列表排序参数加入白名单校验
- 搜索关键词特殊字符转义处理

**审计日志修复**

- 此前审计日志只记录空数据
- 现已完整记录封禁变更前后的数据快照

### 中危安全修复

**会话安全**

- 引入 Redis 会话白名单机制
- 登出后令牌立即失效（不再等 7 天自然过期）
- 修改密码后所有设备强制下线
- 令牌被吊销后无法换取新访问令牌

**登录限流加固**

- 限流从"仅按 IP"改为"IP + 用户名前缀"双重维度
- 防止攻击者轮换 IP 绕过限制

**凭据安全**

- PZ 同步脚本的敏感信息支持从环境变量读取
- 使用默认凭据时记录告警日志

### 部署迁移

- 从树莓派迁移到阿里云服务器
- 数据库完整迁移（用户、封禁、服务器、联系方式）
- 云端环境配置优化

## v1.3 —— 功能扩展

**发布时间**：2026-09-23 下午

**里程碑**：新增三大功能模块

### 公告系统

**显示能力**

- 公开页和面板页顶部显示公告
- 访客可关闭当前会话的公告
- 无公告时自动隐藏

**管理能力**

- 管理员通过侧栏「编辑公告」入口管理
- 支持新增、编辑、删除公告
- 数量限制：**活跃公告最多 5 条，总公告数最多 10 条**
- 支持启用 / 隐藏切换
- 公告编辑页不显示公告本身

### 用户名与 QQ 号管理

**服主自助**

- 个人设置页可修改自己的用户名
- 修改成功后自动登出，需用新用户名重新登录
- QQ 号显示为只读，提示"如需修改 QQ 号，请联系管理员"

**管理员代管**

- 服主管理页可为任意用户修改 QQ 号
- 支持修改管理员自己

### 用户与服务器删除（带数据迁移）

**删除服主账号**

- 管理员可删除服主账号
- 支持将其封禁记录迁移到指定用户
- 支持将其服务器迁移到指定用户
- 多重保护：
  - 不能删除管理员
  - 不能删除自己
  - 不能删除最后一个管理员
  - 迁移时检测 SteamID 冲突

**删除服务器**

- 新增独立的「服务器管理」页面
- 显示所有服务器及封禁数量
- 支持按名称搜索
- 删除时可将封禁记录迁移到其他服务器

### 体验优化

- 服务器列表直接显示封禁数量
- 删除用户前可预览其数据统计
- 公告管理页实时显示"活跃 X / 5 · 总计 Y / 10"
- 前端表单校验与后端一致
